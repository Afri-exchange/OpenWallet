Spendkit is an open-source wallet for AI agents. Fund one card with USDC, give each agent a balance and hard limits, and let it pay over MCP or REST. The card number never reaches the agent.

    how it works

    1. VerifyThe owner passes card KYC once and gets one virtual card.
    2. FundSend USDC on Base to a deposit address. It lands on the card.
    3. BudgetGive each agent a balance, a per-payment cap, a daily cap and allowed categories.
    4. PayAgents pay over MCP or REST. Limits are checked before any money moves.

    connect an agent

    claude mcp add --transport http \
  spendkit http://127.0.0.1:8787/mcp \
  --header "Authorization: Bearer ak_..."
    curl -s http://127.0.0.1:8787/agent/v1/pay \
  -H "Authorization: Bearer ak_..." \
  -H "content-type: application/json" \
  -d '{"amountCents":1250,
       "merchant":"Example API",
       "mcc":"5734",
       "idempotencyKey":"order-1"}'

    MCP tools: get_wallet, pay, list_transactions, get_checkout, pay_checkout, pay_hosted_checkout. One bearer token per agent; revoke it and that agent stops paying at once.

    in the box

    Agent wallets
    Budgets, caps and category allow-lists. Reclaim unspent balance or revoke an agent at any time.
    Checkout
    Merchants create a checkout with one call, hand the agent the link, and are paid out in USDC.
    Developer API
    Embed it in your product: users, a hosted verification page, agents, and signed webhooks.

    status

    • Card issuing and KYC through the Miden sandbox
    • Testnet USDC deposits on Base Sepolia
    • A double-entry ledger in Postgres
    • No real money: sandbox and testnet only
    • Runs on your machine; no hosted service
    • No production key custody, bank payouts or refunds

    The full list is in production-gaps.md. Running it needs Miden sandbox credentials.
