Give your agents a budget, not your card.

Spendkit gives every AI agent its own wallet with hard limits. Fund one card with USDC, hand each agent a budget, and let it pay over MCP or REST. The card number never reaches the agent.

    // how it works

    One card. A wallet for every agent.

    1. 01

      Verify

      The owner passes card KYC once and gets one virtual card.

    2. 02

      Fund

      Send USDC on Base to a deposit address. It lands on the card.

    3. 03

      Set budgets

      Give each agent a balance, a per-payment cap, a daily cap and allowed categories.

    4. 04

      Agents pay

      Over MCP or REST. Every payment is checked against the limits before money moves.

    // what is in the box
    
    
    Three pieces, one ledger.
    
    
    
      
    
        
    ▚Agent wallets
    
        
    Budgets, per-payment and daily caps, category allow-lists. Retries with the same key never pay twice. Reclaim unspent balance or revoke an agent at any time.
    
      
    
      
    
        
    ▞Checkout for merchants
    
        
    Create a checkout with one call and hand the agent the link. The agent pays from its wallet, and you are paid out in USDC.
    
      
    
      
    
        
    ▙Developer API
    
        
    Embed it in your product: create users, hand them a hosted verification page, manage their agents, and receive signed webhooks.
